# ascii-bonsai

Bonsai vivo em ASCII para o desktop (Hyprland + Quickshell): cresce com o tempo, muda com hora, mês e temperatura (hemisfério sul), solta folhas, e aceita poda com clique esquerdo e arame com clique direito.

Em construção. Plano:

1. Usar o motor do git-bonsai (MIT) para gerar a árvore em pixel art e converter cada bloco de pixels em uma célula de caractere (tile colorido + glifo), no mesmo estilo do lago de carpas do `omarchy-dotfiles`.
2. Trocar os dados do GitHub por clima, data e hora; crescimento por fases reais (brotação, alongamento, endurecimento, dormência).
3. Poda: remover nuvens de folhas e galhos do esqueleto; rebrota na primavera. Arame: dobrar o galho aos poucos, com risco de marcar a casca.
4. Plugin do Quickshell para o desktop, com botão e painel na barra.
